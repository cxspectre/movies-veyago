# S1-C: the pop-up paper component (cloud, Sonnet Medium or Opus, cap about $12)

Read first: `CONTRACT.md` (section 13 especially), `docs/v4/PLAN.md`, `docs/v4/BIBLE4.md` section 5 for the chapters that fold, lift or pop up (5.2 Maya's house, 5.3 the letters and the crumple and scissors, 5.4 the filter machine, 5.8 the rocket, 5.9 the houses of the village), `src/paper/README.md` (the v1 pencil-and-paper engine, shadow helpers, the lamp), `src/desk/` (props and shadows, to match the light).

Branch `claude/s1c-popup`, open a PR to `main`. Cloud rules: stills only, `FILM_GL=swangle` if you use WebGL, never commit `package-lock.json`, no sub-agents. Stop at the cap and report.

## Deliver (in `src/popup/**`, registered through a new `src/popup/previews.ts` that you add to `src/previews4.ts`)
1. **`<PopUp>`**: lifts a flat drawing (any React children, normally a pencil drawing) into a paper object with real-looking **folds**: hinge lines you describe as data (fold axis, angle over time, which panel), perspective via 2.5D transforms (CSS 3D `rotateX/rotateY`, or three.js with paper panels if the result is clearly better and still deterministic), a soft one-sided lamp shadow that follows the lamp direction of the v1 desk (BIBLE.md 2.1), a thin paper edge so the panels have thickness, and paper tooth on the panels. Deterministic (`random(seed)` only). Never use CSS `mix-blend-mode` (it breaks in Remotion's Chrome; see `src/paper/README.md`).
2. **Presets** built on it that the chapters need, as small data files: a house whose front wall opens like a dollhouse (BIBLE4 5.2), a sheet that crumples into a ball and unfolds into a drawing (5.3), a tall machine that folds up from the page (5.4), a rocket that folds up on a launchpad (5.8), a small house that pops up with a door label (5.9). One generic fold animation can serve several; make the presets differ in data, not code.
3. **Proof**: compositions `PopUp-demo-wide` and `PopUp-demo-tall` showing the house opening, the crumple and the rocket folding up, rendered as stills at several frames (scale 1, a few at scale 2) into `out/review/s1c/`. LOOK at them: folds must read as paper, shadows must be consistent, no visible seams or flicker between consecutive frames (render two adjacent frames to check). Measure and record the render time per frame in `src/popup/README.md`, with usage for chapter owners.
4. `npx tsc --noEmit` and `zsh tools/checkRules.sh` must pass.
